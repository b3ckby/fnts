Сложность 1-5 считается двумя независимыми сигналами, без смешивания друг с другом: (1) атака/защита по xG — собственная реализация идеи Fantasy Football Scout (режим Relative), не воспроизведение их проприетарной формулы: своя средняя результативность клуба за сезон 2025/26 (understat.com), умноженная на то, насколько атака/оборона соперника отличается от средней по лиге, плюс домашняя поправка (эмпирическая, по факту разницы дома/в гостях в самой лиге); в 1-м туре дополнительно подмешаны 50/50 коэффициенты Winline «сухой матч»/«тотал >1.5» через пуассоновскую модель — дальше линий у букмекера нет. (2) Elo-рейтинг от ClubElo (clubelo.com) — независимый открытый рейтинг, непрерывный с 1939 года и откалиброванный по всем лигам мира, а не только внутри РПЛ. Режим «ВР/ЗАЩ» — насколько вероятно пропустить; «ПЗ/НАП» — насколько вероятно забить (инвертировано в сложность); «Elo» — общая сила команд без разбивки на атаку/защиту; «Все» — среднее ВР-ЗАЩ/ПЗ-НАП (Elo в это среднее не входит). У Родины и Факела (поднялись из Лиги Pari) нет истории в РПЛ — для xG/xGA и Elo взято среднее по 3 худшим клубам лиги, посчитанное скриптом сбора данных. Сортировка по «Ср. сложность» по возрастанию показывает клубы с самым лёгким отрезком.
